# Roadmap and Scope

Principle: **Build for what exists. Structure for what is likely. Leave room for what is possible.**

## V1

- Home
- Projects
- Notes
- Now
- About
- Contact
- CV view/download
- Astro + TypeScript + HTML
- custom CSS with BEM
- design tokens via CSS custom properties
- responsive layout and accessibility
- structured Project and Note content
- tags stored as metadata
- optional repository/live/external links
- optional galleries and video
- optional project demo/download/changelog when a real project needs one
- relevant GitHub links
- SEO basics, metadata, sitemap and social previews
- deployment/security review before launch

## Architect for, but do not surface until useful

- public tag browsing/filtering
- related-content recommendations
- site search
- free downloads/resource library
- richer interactive project demos
- interactive experiments
- product pages
- product documentation
- RSS for Notes
- automated GitHub metadata where it adds value

## Later, only when there is a real need

### Commerce

- Shop / paid digital products
- external payment/commerce provider
- purchase records and entitlements
- re-downloads

### Customer application

Potentially a separate ASP.NET Core application, e.g. `account.rolinavorster.com`, for:

- authentication
- customer dashboard
- purchases
- downloads
- licences
- subscriptions
- billing management
- profile/customer data

### Optional publishing/community features

- newsletter: only if Rolina actually wants to send one
- comments/discussion: currently not planned; external discussion/contact is preferred unless a compelling reason emerges
- speaking section: only when there is meaningful speaking content
